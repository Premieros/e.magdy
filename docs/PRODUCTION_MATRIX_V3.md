# المرحلة الثالثة — دفعات المقاسات والألوان وحزم القص

## الجديد
- إنشاء **دفعة إنتاج (LOT)** لموديل واحد، مع مصفوفة كميات لكل تقاطع مقاس/لون.
- توليد **أوامر تصنيع منفصلة لكل SKU** داخل الدفعة، للحفاظ على الصرف والجودة والتكلفة الخاصة بكل صنف.
- صفحة دفعات المقاسات تعرض إجمالي الكميات وتقدم التنفيذ، مع صفحة تفصيلية لمصفوفة الكميات ومراجع أوامر التصنيع.
- تسجيل **حزم قص** اختيارية لكل أمر قبل بدء القص، مع رقم الحزمة والكمية وملاحظة.
- عند وجود حزم قص مسجلة، يمنع النظام بدء القص حتى يتساوى إجمالي الحزم مع كمية أمر التصنيع.
- الحفاظ على عمل الأوامر القديمة دون إلزامها بإنشاء حزم؛ لا يتم تغيير شكل البيانات الموجود أو رقم الإصدار 1.
- إضافة `cuttingBundles` إلى النسخ الاحتياطية المحلية والسحابية بشكل اختياري متوافق مع النسخ السابقة.

## طريقة الاستخدام
1. عرّف موديلًا بالمقاسات والألوان وأضف قائمة BOM له.
2. من «دفعات المقاسات» اختر «دفعة مقاسات وألوان» وحدد كميات SKU المطلوبة.
3. يعرض النظام الدفعة مع أوامر مستقلة، ثم يمكنك فتح كل أمر.
4. اختر «إضافة حزمة قص» قبل بدء القص، إذا احتجت تتبع رصّات القص. إذا سجلت حزمة أولى، يجب إكمال بقية الحزم حتى تساوي كمية الأمر.
5. ابدأ القص لصرف المواد من مخزون ذلك الأمر فقط، ثم تابع الخياطة والتشطيب والجودة كما في السابق.

## حدود مهمة
- دفعة المقاسات هي **تجميع للتخطيط فقط**، وليست أمر صرف مواد إضافيًا؛ كل أمر SKU يصرف الخامات بصورة مستقلة. لذلك لا يوجد خصم مضاعف لمجرد إنشاء الدفعة.
- لا يوجد بعد صرف خامات موحد ومتزامن لجميع أوامر الدفعة؛ إذا كان المخزون غير كافٍ، قد يبدأ قص بعض الأوامر ويبقى بعضها مخططًا، ويظهر الوضع في كل أمر.
- لا يتم تتبع الحزمة عبر مراحل التشغيل التالية برقمها؛ سجلات العمال مرتبطة بالأمر والمرحلة فقط.
- لا توجد إدارة استرجاع قص، أو فاقد/إعادة عمل، أو طلبات بيع مترابطة مع الدفعة حتى الآن.
- النسخة تجريبية `localStorage` لجهاز واحد؛ لا تستخدم بيانات تشغيل حقيقية متعددة الأجهزة قبل إكمال قاعدة البيانات وصلاحيات المستخدمين والمعاملات الذرية.
- مشروع AMMCO المشترك لم يتم تغييره في هذه المرحلة؛ تظل النسخ السحابية **يدوية واختيارية** لكل مستخدم.

## الجداول المستهدفة لاحقًا في PostgreSQL
`garment_production_lots`, `garment_production_lot_lines`, `garment_work_orders`, `garment_cutting_bundles`, `garment_cutting_bundle_issues`, `garment_work_order_movements`.
