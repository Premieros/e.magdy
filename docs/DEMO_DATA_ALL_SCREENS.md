# بيانات العرض الشاملة — PremierOS Garments

**هذه أمثلة خيالية فقط، وليست بيانات شركة أو عميل حقيقي.**

## التشغيل

1. افتح [المعاينة على GitHub Pages](https://premieros.github.io/e.magdy/).
2. على متصفح خالٍ من بيانات المصنع اختر زر **ملء جميع الشاشات ببيانات تجربة** من لوحة التحكم، أو افتح **النسخ الاحتياطي → تحميل بيانات تجربة شاملة**.
3. وافق على التنبيه. ينشئ النظام سجلات مترابطة عبر وظائف الإنتاج والبيع الحقيقية داخل الكود، وليس جداول عرض مزيفة.
4. ستجد شريطًا أصفر أعلى كل شاشة يوضح أن البيانات **افتراضية للعرض**، وأن النسخ السحابي لها معطّل.
5. إذا كان في المتصفح بيانات سابقة: صدّر أولًا نسخة `JSON` من شاشة النسخ الاحتياطي؛ بعد التأكد من التنزيل يمكن إعادة ضبط **البيانات المحلية فقط** من نفس الشاشة، ثم تحميل بيانات العرض.

**لا يكتب الزر أي بيانات في Supabase أو AMMCO**؛ كل شيء يبقى داخل متصفحك باستخدام `localStorage`. لن يتم ملء بيانات تلقائيًا لمستخدمي الموقع؛ يجب طلب العرض صراحةً.

## تغطية الشاشات

| الشاشة | المحتوى التجريبي |
|---|---|
| لوحة التحكم | أعداد الموديلات والأوامر والمنتج التام وتنبيه انخفاض رصيد |
| الموديلات | ثلاثة موديلات: قميص وتيشيرت وجاكيت، بمجموع 18 مقاسًا/لونًا SKU |
| الأقمشة والخامات | 9 خامات وإكسسوارات بحركات استلام وصرف وتكلفة مرجحة |
| رولات الأقمشة | أربعة رولات مختلفة للقطن والجيرسي والبطانة مع الرصيد المتبقي |
| العمال والإنتاجية | خمسة أفراد افتراضيين، وسجلات تشغيل القص والخياطة والتشطيب |
| أوامر الإنتاج | أوامر مخططة وقص وخياطة وتشطيب وجودة ومكتملة |
| دفعات المقاسات | دفعة قميص تحتوي على عدة SKU وأوامر منفصلة |
| مراقبة الجودة | أوامر تنتظر الفحص وأوامر مفحوصة بها مقبول ومرفوض |
| بيع الجملة والتسليم | ثلاثة طلبات تشمل الحالات: مفتوح، مسلّم جزئيًا، مكتمل، وإذنا تسليم |
| التقارير | رصيد تام حسب المقاس واللون، وحركات خامات، وأذون التسليم وسجل العمليات |
| النسخ الاحتياطي | تصدير واستيراد JSON محلي؛ **الرفع السحابي معطّل في وضع العرض** |

## سلامة البيانات

- لن يُحمل العرض إذا كانت أي سجلات تشغيل فعلية موجودة في المتصفح، بما فيها الطلبات والرولات والمخزون والتسليم.
- لا يغيّر عرض البيانات القاعدة المشتركة `yumeijsyiphzdsulsubf` ولا النظام الأصلي PremierOS.
- النظام يبقى نموذجًا محليًا لا يدعم التعاون بين عدة موظفين. لا ترسل هذا الوضع للعميل لبدء تسجيل طلباته الحقيقية.
- **تجهيز نسخة تشغيلية** يحتاج تسجيل دخول وصلاحيات فريق العمل، وعزل مؤسسة المصنع، ودفاتر مخزون وأوامر خادمية متزامنة ومعاملات PostgreSQL ذرية، واختبار الاسترداد والتزامن.
