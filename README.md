# PremierOS Garments — مصنع الملابس

نظام إدارة مصانع الملابس، مستقل عن PremierOS الأصلي.

**حالة المشروع:** نسخة أولية للتجربة، دون قاعدة بيانات سحابية. الحفظ المحلي داخل المتصفح فقط، وليس مناسبًا للبيانات الإنتاجية الحقيقية أو العمل متعدد الأجهزة.

## المكونات
- الموديلات مع المقاسات والألوان وكود SKU لكل متغير
- الأقمشة والخامات والاستلام وحركة المخزون
- قوائم المكونات BOM وصرف الخامات عند بدء القص
- أوامر التصنيع ومراحل القص والخياطة والتشطيب وفحص الجودة
- حساب تكلفة الخامات والتشغيل والإنتاج المقبول
- التقارير والنسخ الاحتياطي

## التشغيل
افتح التطبيق على أي خادم ملفات ثابت، مثل:

```bash
python3 -m http.server 3000
```

ثم افتح http://localhost:3000. لا تتطلب هذه النسخة مكتبات خارجية.

**البيانات:** لا يوجد اتصال بقاعدة PremierOS السابقة، ولا قاعدة Supabase متاحة لهذه النسخة حاليًا.

## لاحقًا
إنشاء قاعدة PostgreSQL/Supabase خاصة بالمشروع، Auth والصلاحيات وسياسات RLS، ونقل عمليات الإنتاج والمخزون إلى معاملات خادمية ذرية قابلة للمراجعة.
